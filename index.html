Hermes Faith

Hermes Faith is a private, single-user assistant for reading reference materials, discussing study questions, and organizing personal study notes. The assistant runs on its operator's private server and is used through Telegram. It is not a public sign-up service.

Google Drive access

The operator connects a dedicated Google account to let the assistant read reference materials and create or update study records. Google Drive sharing permissions determine which files that account can access. The assistant is instructed to work within designated reference and output folders. The requested Drive permission is account-wide; these folder instructions are not a separate Google-enforced OAuth scope.

This information website does not provide access to the assistant, Google Drive files, or the private server. It contains no sign-in form or file upload feature.

Read the Privacy Notice for details about data handling. The sole user manages the assistant and its Google authorization directly.
