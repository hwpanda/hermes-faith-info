Hermes Faith — Privacy Notice

Last updated: October 12, 2026

Purpose and data accessed

Hermes Faith is operated for personal study by its sole user. With that user's authorization, the assistant can access Google Drive file names, folder information, file contents, and file metadata available to the connected Google account. It uses this information to retrieve reference materials, answer questions, and save study records. The Google integration requests Drive access; it does not request Gmail, Calendar, or Contacts access.

Processing and recipients

Relevant file excerpts and conversation context may be sent to the configured AI model provider to produce responses. Requests and replies pass through Telegram when the user interacts with the bot. Google processes Drive API requests. Conversation history, downloaded material, and operational records may be stored on the operator's private server, and generated study records may be saved to Google Drive. These services process data according to their applicable terms and privacy policies.

Storage and control

Google authorization credentials are stored separately on the private server with restricted file permissions. The assistant uses the connected account's existing Drive sharing permissions. The operator can revoke the Google connection, remove shared-folder access, and delete stored files or conversation records. Revoking access stops future access but does not automatically delete previously stored copies. Records remain until removed by the operator or the configured retention processes; this notice does not promise a fixed automatic deletion period.

Public website

This website publishes only the application description and this notice. It does not host study materials, conversation history, credentials, or private server addresses. No advertising or analytics scripts are added to these pages. GitHub Pages, as the hosting provider, may log visitors' IP addresses for security purposes under the GitHub Privacy Statement.

Changes and questions

The sole user is also the operator and manages data requests directly. This notice should be updated if the integration, service providers, intended audience, or data handling changes.
